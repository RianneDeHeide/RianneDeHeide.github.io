# Website redesign preview

This is a conservative Jekyll migration of the existing riannedeheide.github.io site. The live-site content was used as supplied in the uploaded repository; the first redesign focuses on structure and maintainability rather than rewriting.

For a GitHub Pages preview repository named `website-redesign-preview`, `_config.yml` is already set to the correct base URL. Before replacing the live user site, replace `_config.yml` with `_config_live.yml` (or set `baseurl: ""`).
